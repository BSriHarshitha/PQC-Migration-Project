Hybrid RSA-2048 + Kyber-1024 + Dilithium-5

Migration-Safe · Backward Compatible · KEM Combiner Pattern (Giacon PKC 2018)

🔗
Hybrid = RSA-2048 + Kyber-1024 + Dilithium-5 running simultaneously Key exchange: SHA-256(rsaSecret ∥ kyberSecret) → 32-byte AES-256 key (KEM Combiner, Giacon PKC 2018). Signatures: both SHA256withRSA and DilithiumSigner must verify. If RSA is broken by quantum → Kyber still protects. If Kyber has a flaw → RSA still protects. Attacker must break both simultaneously — near impossible. Actual measured timings: Init ~1126ms, Key Exchange ~19ms, Encrypt ~12ms, Decrypt ~0ms, Sign ~50ms, Verify ~8ms, AES Key 32B, Hybrid Valid ✓ TRUE.
